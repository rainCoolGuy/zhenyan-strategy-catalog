# Noto Sans SC（自托管）

本目录提供真言门策略目录使用的 **Noto Sans SC** 可变字体（字重轴 100–900），避免依赖 Google Fonts，也避免把 Segoe UI 放在字体栈首位导致中西文错配。

- 源文件：<https://github.com/notofonts/noto-cjk> 中的 `Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf`
- 子集：Latin、CJK 标点、全角符号、GB2312 简体汉字，以及本目录页面中用到的额外字符
- 格式：WOFF2 可变字体 `NotoSansSC-VF.woff2`（约 1.8MB，一份覆盖 400/500/600/700）
- 许可：SIL Open Font License 1.1，全文见 `OFL.txt`

这些文件与 `auth.js` 一样保持明文，不要加密进 `enc/`。
